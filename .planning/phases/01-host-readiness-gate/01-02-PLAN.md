### CLI contract

| Command | Result |
|---|---|
| `replay-host-doctor run --evidence <PATH> [--probe-timeout-ms <N>]` | Fresh live run, current evidence write/readback, G0 FAIL until all native extensions pass |
| `replay-host-doctor diagnose --fixture <PATH> --evidence <PATH>` | Explicit diagnostic run; fixture observations can never be live-admissible |
| `replay-host-doctor verify-evidence --evidence <PATH> --run-id <ID>` | Read-only V1 base/integrity/current-run verification; known extension checks are optional and separately requested later |

The documented development command is:
`cargo run --locked --bin replay-host-doctor -- run --evidence target/g0-evidence.json`.

| Boundary | Description |
