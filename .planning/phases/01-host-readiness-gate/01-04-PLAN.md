device, inode, and size metadata. Copy and calculate the source digest only
from that open descriptor; never reopen or resolve the source path for bytes

`archive_proc_self_exe_magic_link_source_open` regression, which must
successfully copy/hash the running executable and therefore catches an ELOOP

no-follow, path-containment, and create-new protections to every destination

a read-only `pre_reboot_archive_manifest_path_digest_schema` assertion that
consumes an existing immutable index for Task 2.

component relative to the verified run directory, checks type/mode/size/digest,

the archived binary.
