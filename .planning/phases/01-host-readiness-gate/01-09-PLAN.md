### Closed policy

1. H.264 High / 4:2:0 / 8-bit / NV12.
2. HEVC Main / 4:2:0 / 8-bit / NV12.
3. HEVC Main10 / 4:2:0 / 10-bit / YUV420_10BIT.
4. HEVC FREXT / 4:4:4 / 8-bit / YUV444.
5. HEVC FREXT / 4:4:4 / 10-bit / YUV444_10BIT.
6. AV1 Main / 4:2:0 / 8-bit / NV12, Ada-or-newer only.
7. AV1 Main / 4:2:0 / 10-bit / YUV420_10BIT, Ada-or-newer only.

Every position is 3840x2160 at exact 60/1 and receives one terminal attempt
record, including generation-ineligible/unsupported results.
