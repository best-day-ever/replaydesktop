gateway worker, UniFi adapter, token verifier, tests, and runbook.

<threat_model>

| Threat | Severity | Mitigation |
|---|---:|---|
| Password/database disclosure | high | Argon2id PHC hashes, opaque token digests, bounded inputs, no credential logging |
| Unauthorized workstation selection | high | Active grant checked at request and knock consumption |
| HTTPS/UDP source mismatch | high | Exact one-use UDP knock; HTTPS peer alone never opens a lease |
| UniFi credential misuse | high | Private configuration, verified TLS, narrow adapter, owned policy IDs only |
| Ticket forgery/replay | high | Ed25519, exact algorithm/issuer/audience/source/time validation, bounded token, one-use JTI contract |
| Stale firewall exposure | high | Stored lease IDs, expiry worker, idempotent close, startup reconciliation |
| Media disclosure | high | No media listener/relay; direct Kymux TLS and enrolled certificate fingerprint |

</threat_model>
