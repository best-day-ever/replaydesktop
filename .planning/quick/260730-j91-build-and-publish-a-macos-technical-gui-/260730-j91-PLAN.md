# ReplayDesktop technical client GUI spike

## Task 1: Build the native technical launcher and live telemetry panel

**Files**

- `prototype/macos/ReplayDesktopLauncher.swift`
- `scripts/package-macos-gui.sh`
- `README.md`
- Existing bundle inputs under `upstream/kyber-desktop/kyclient/res/`

**Action**

- Add a programmatic AppKit launcher, compiled as Apple Silicon and installed as
  the bundle executable while retaining the original `kyclient` binary as the
  streaming engine and direct CLI fallback.
- Provide host/IP, port, codec (`H.264`, `HEVC`, `HEVC 4:4:4`, `AV1`), total
  video bitrate, single display index versus multi-monitor count, audio enable,
  audio buffer, Kymux audio transport, input, clipboard, keyboard-grab, and
  Connect/Disconnect controls.
- Reject AV1 4:4:4, require Kymux for multi-monitor, and label total bitrate as
  shared across active displays.
- Build every child argv from the exact proven fixed baseline:
  `--port=8080 --protocol=kymux --tls-skip-verification --video-buffer=0
  --metrics=true --auto-reconnect=false`, then add only validated GUI-controlled
  arguments. Retain `Contents/MacOS/kyclient` as the raw CLI entry point.
- Show clipboard as **Unavailable in this macOS build** and do not pass
  `--clipboard=true`. Label keyboard behavior as focused-window forwarding;
  system shortcuts are not suppressed. Keep the input toggle functional.
- Mark H.264 4:2:0 as the proven baseline. Mark HEVC 4:2:0, HEVC 4:4:4, and
  AV1 4:2:0 as experimental/manual until the exact host/client path succeeds.
  Never construct or offer AV1 4:4:4.
- Launch the child in a writable Application Support directory, capture
  stdout/stderr, and tail the live `metrics.json` and Kyber log into a bounded
  technical metrics view.
- Persist non-secret prototype preferences locally. Keep LAN mode free of CA,
  JWT, username, and password setup.
- Make the packaging script deterministic, update `CFBundleExecutable`, retain
  minimum macOS 15 and arm64-only checks, ad-hoc sign, and verify the bundle.
- Record the internal-only signing/trust exceptions in the release notes. Do
  not present this asset as notarized or production-safe.

**Verify**

- Compile the launcher with:
  `xcrun --sdk macosx swiftc -parse-as-library -target
  arm64-apple-macos15.0 prototype/macos/ReplayDesktopLauncher.swift -framework
  AppKit -o ReplayDesktopLauncher`.
- Run a launcher argument-construction self-test or dry-run matrix covering all
  codec, display, and audio combinations, including invalid AV1 4:4:4.
- Run `scripts/package-macos-gui.sh --dry-run` and
  `scripts/verify-gui-spike.sh`; the latter must execute `plutil -lint`,
  assert `CFBundleExecutable=ReplayDesktopLauncher`, inspect every Mach-O with
  `file`, inspect minimum OS with `otool -l`, run
  `codesign --verify --deep --strict`, assert writable runtime paths, verify
  the raw CLI `--help`, and fail if test identities are present.

**Done**

- Double-clicking the app opens the panel; Connect starts the same working
  Kyber command, Disconnect terminates only the session child, and telemetry
  visibly updates without modifying the media path.
