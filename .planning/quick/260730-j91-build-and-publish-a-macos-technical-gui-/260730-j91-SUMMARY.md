## Accomplishments

- Added a Finder-launchable AppKit technical panel with honest codec, chroma,
  display, audio, input, keyboard, clipboard, lifecycle, and telemetry
  behavior while retaining `Contents/MacOS/kyclient` as the unchanged engine

## Decisions Made

- The fixed default command has exactly one port argument. A GUI port replaces
  the `--port=8080` baseline slot rather than appending a duplicate Clap option.
- Multi-monitor stays on Kymux and emits the existing bounded
  `--display-count`; the GUI labels configured bitrate as total/shared.
- Audio maps only to the existing single Kyber audio service and Opus path.
  No working-audio claim is made while the current monitor format fails.
- Input maps to both mouse and focused-window keyboard forwarding. macOS
  immersive system-shortcut suppression is not offered or implied.
- Engine provenance distinguishes immutable executable payload bytes from the
  mutable code-signature envelope needed for a valid deep-signed app bundle.
- Packaging accepts only an explicit release version and a committed,
  ancestor-checked base/head pair whose deterministic diff digest matches the
  supplied value.
- The final archive is accepted only if it is manifest-identical to the
  fully qualified app, preventing a clean side app from masking a different
  uploaded ZIP.
- Publication uses a superseding version when correctness changes after an
  immutable release; released assets are never overwritten.
