## Event contract

The additive public record is a fixed-capacity v1 structure with
`version`, `struct_size`, `kind`, `producer_seq`, VLC monotonic timestamp,
optional PTS validity/value, typed numeric fields, bounded NUL-terminated text,
and one coherent cumulative callback-loss tuple
`{events, first_seq, last_seq, generation}`. Newer producers set `struct_size`;
older consumers ignore trailing bytes. Unknown values are represented by a
typed reason enum, never `0`, `false`, an empty module name, or inferred state.
Callbacks return accepted/rejected and receive pointers valid only for the
call. The later Rust bridge must deep-copy the record. Callback installation is
one-time and immutable for a player run: either setter may create the shared
publisher, the other may attach its still-unset callback before playback, and
duplicate or active-playback replacement fails explicitly. This avoids racing
callback/sys replacement with inherited-object producers.

The publisher uses fixed storage and a one-attempt versioned atomic snapshot,
equivalent in boundedness to `260730-swz`: writers never wait; an overlapping
loss snapshot is omitted until a later ordinary event; cumulative totals remain
monotonic; first/last sequences are true min/max for the accumulated epoch.
